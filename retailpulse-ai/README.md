# RetailPulse AI

## Overview
RetailPulse AI is a retail analytics web application designed to turn store-level retail data into accessible performance dashboards. The project demonstrates how operational data can be cleaned, summarized, and presented to support faster, data-informed decisions.

## Business question
How can retail leaders compare store performance, identify KPI trends, and investigate operational gaps without manually reviewing disconnected spreadsheets?

## Project workflow
1. Load retail sales, operational, and customer-related datasets.
2. Clean and standardize fields with Python and Pandas.
3. Calculate KPIs such as revenue, units sold, average transaction value, goal attainment, and store performance trends.
4. Present findings in an interactive Streamlit dashboard.
5. Use feedback to improve dashboard usability and decision relevance.

## Tools
Python, Pandas, Streamlit, Excel/CSV, Jira, Asana, Trello
