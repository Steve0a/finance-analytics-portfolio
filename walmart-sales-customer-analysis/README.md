# Walmart Sales & Customer Analysis

## Overview
This project brings together sales and customer data from multiple CSV files to identify performance trends and turn raw data into business insights. The project is designed as a portfolio example of data integration, analysis, and executive-ready storytelling.

## Business question
Which products, locations, customer segments, and time periods drive sales performance, and what trends should decision-makers investigate?

## Project workflow
1. Combine multiple sales and customer data sources.
2. Clean inconsistent fields, missing values, and duplicate records.
3. Analyze sales trends by product, category, store, customer group, and time period.
4. Build summary tables and charts for stakeholder review.
5. Document findings, assumptions, and recommended actions.

## Tools
Python, Pandas, Excel, Tableau or Power BI, CSV data
