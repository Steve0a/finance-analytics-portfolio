# Customer Feedback NLP Analysis

## Overview
This project analyzes customer comments to identify recurring themes, sentiment patterns, and actionable service or product issues. It shows an end-to-end workflow from unstructured text cleaning to stakeholder-ready visualization.

## Business question
What issues and themes appear most often in customer feedback, and how can those findings guide product, service, or operational improvements?

## Project workflow
1. Clean and normalize text data in Python and Excel.
2. Remove duplicates, null values, and non-informative text.
3. Explore keyword frequency, recurring themes, and sentiment indicators.
4. Summarize insights with Tableau or Power BI visualizations.
5. Present recommendations in plain business language.

## Tools
Python, Pandas, NLTK, Excel, Tableau, Jira, Microsoft 365

## Evidence to add

## Resume-ready impact
Cleaned and structured customer comments using Python and Excel, then translated thematic findings into business-facing Tableau dashboards and recommendations.
