# Finance Analytics Portfolio

Portfolio of finance, business analytics, dashboard, and AI research projects by Steve Okyere Oduro-Amoyaw.

## Focus
- Finance operations, reporting, risk, and data quality
- SQL, Python, Pandas, Excel, Tableau, Power BI, and Streamlit
- KPI dashboards, forecasting inputs, data storytelling, and process improvement
- Responsible AI-assisted research and due-diligence workflows

## Projects
| Project | What it demonstrates | Tools |
|---|---|---|
| [RetailPulse AI](retailpulse-ai/) | Retail KPI dashboard and operational analytics application | Python, Pandas, Streamlit, CSV data |
| [Customer Feedback NLP Analysis](customer-feedback-nlp-analysis/) | Customer-comment cleaning, theme analysis, and insight visualization | Python, Pandas, NLTK, Excel, Tableau |
| [Walmart Sales & Customer Analysis](walmart-sales-customer-analysis/) | Multi-source sales and customer trend analysis | Python, Pandas, Excel, Tableau/Power BI |

## Repository structure
Each project includes a README, folders for data or research materials, and placeholders for notebooks, source code, dashboards, and outputs. No confidential employer, client, student, or personally identifiable data is included.
